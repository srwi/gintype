# Changelog

## [4.2.0] - Initial Public Release

### Included Patches
- **Nintype Multi-Touch Swipe**: Two-finger swipe and tap+swipe chorded gesture typing integrated with Gboard's native dictionaries, Material You secondary trail accent color, slider tuning controls, and configurable trace log export.
- **Matrix Word Suggestions**: 2D vertical suggestion grid with swipeable word wheels, sentence branch history, jump-to-end shortcut, and Gboard accent-matched styling.
- **Package Rename**: Optional side-by-side package rename (`dev.srwi.com.google.android.inputmethod.latin`) with customizable app name (`Gboard Multiswipe` by default).
- **Isolated Namespace**: Independent `dev.srwi.gboardmultiswipe` namespace and `Multiswipe & Matrix` settings entry (`gboard_multiswipe_entry`) for conflict-free operation.
